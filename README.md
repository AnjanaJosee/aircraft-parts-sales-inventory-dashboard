
# Aircraft Parts Sales & Inventory Dashboard

## Project Overview
An interactive Power BI dashboard developed to analyse aircraft parts sales, customer activity, product performance, and regional sales trends. The project demonstrates how business data can be transformed into meaningful insights to support data-driven decision-making.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modelling
- Microsoft Excel

## Data Model
The dashboard uses four tables:
- Sales
- Products
- Customers
- Date

## Key Features
- Sales performance analysis
- Total units sold and revenue tracking
- Product and customer analysis
- Regional sales performance
- Monthly sales trends
- Interactive filtering and visualisations

## Key Skills Demonstrated
Data cleaning, data transformation, data modelling, table relationships, DAX measures, KPI development, and dashboard design.
